ClipDock - clipboard history that pastes where your cursor is
==============================================================

INSTALL (30 seconds)
  1. Install Python from https://www.python.org/downloads/ if you don't have it
     (tick "Add python.exe to PATH" during setup).
  2. Double-click  install_shortcut.bat
  3. Done! Open "ClipDock" from your Desktop or Start menu.

HOW TO USE
  - Copy anything (Ctrl+C) - it appears in ClipDock.
  - Click an item to paste it at your cursor, in any app.
  - MOVE: drag the window from any empty spot (or drag an item).
  - RESIZE: drag any edge or corner. Size and position are remembered.
  - NAME: click the pencil on an item, type a name, press Enter.
    Search then finds items by their text OR their name.
  - DAY / NIGHT: click the sun/moon button in the header.
  - Hover any button to see what it does.

UPDATE
  Download the newest zip from the website, unzip, and run install_shortcut.bat
  again. Your history is kept.

Windows blocked it? Smart App Control blocks unsigned .exe files. ClipDock runs
as a script through Python, so it is not affected.
