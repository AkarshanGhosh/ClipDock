How it works

Up and running in a minute

Three simple steps. You only set it up once.

1

Download

Grab the zip with the button above and unzip it anywhere.

2

Install

Double-click install_shortcut.bat. It sets up Python if you need it, replaces any older version and adds ClipDock to your Desktop and Start menu.

3

Copy & click

Copy as usual with Ctrl+C. Click an item in ClipDock to paste it at your cursor.

Prefer a single file? Download ClipDock-Setup.bat. It downloads the latest ClipDock and installs everything, Python included.

Help

Quick answers

Do I need to install Python first?

No. install_shortcut.bat checks for Python and, if it is missing, downloads and installs it for you (one time, about 1–2 minutes, no administrator needed). Python is the free, official one from python.org.

Windows says a file is blocked (Smart App Control)

Smart App Control blocks unsigned .exe programs. ClipDock isn't an .exe. It runs through Python, so it isn't affected. Use install_shortcut.bat from the zip rather than any .exe file.

How do I update to the newest version?

Download the latest zip from this page and run install_shortcut.bat again. It removes the old version, installs the new one and keeps your clipboard history. You can also run ClipDock-Setup.bat. ClipDock checks for updates by itself too: when one is ready, an Update ↗ note appears in its header.

How do I name an item and find it later?

Click the pencil ✎ on any item, type a name (for example “Work email”) and press Enter. The name shows above the text, and the search box finds items by their text or their name.

Can I move or resize the window?

Yes. Drag it from any empty spot (or drag an item) to move it, and drag any edge or corner to resize it. ClipDock remembers its size, position and day/night mode next time.

Is my clipboard data private?

Completely. Your history is stored only on your own computer and is never uploaded anywhere. Copied passwords would be saved in the history too, so use the pause button (●) when copying sensitive things.

Windows says “Windows protected your PC”

That is SmartScreen, which warns about any downloaded file it hasn’t seen often. Click More info → Run anyway. The installers are plain text .bat files you can open and read.

It pasted nothing in my admin / elevated app

Windows stops normal programs from sending keystrokes to apps running as administrator. Start ClipDock as administrator too, and it will work there.

How do I uninstall it?

Run uninstall_clipdock.bat (it is in the zip and in %LOCALAPPDATA%\ClipDock). It removes the app and shortcuts and asks whether to delete your history as well.
