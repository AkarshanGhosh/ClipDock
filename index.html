Help

Quick answers

Do I need Python?

Yes, a free one-time install from python.org (tick “Add python.exe to PATH”). ClipDock runs as a lightweight script through Python, so there's nothing else to install.

Windows says a file is blocked (Smart App Control)

Smart App Control blocks unsigned .exe programs. ClipDock isn't an .exe. It runs through Python, so it isn't affected. Use install_shortcut.bat from the zip rather than any .exe file.

How do I update to the newest version?

Download the latest zip from this page and run install_shortcut.bat again. It replaces the old files and keeps your clipboard history. ClipDock also checks for updates by itself. When one is ready, a small Update ↗ note appears in its header.

Is my clipboard data private?

Completely. Your history is stored only on your own computer and is never uploaded anywhere. Copied passwords would be saved in the history too, so use the pause button (●) when copying sensitive things.

It pasted nothing in my admin / elevated app

Windows stops normal programs from sending keystrokes to apps running as administrator. Start ClipDock as administrator too, and it will work there.

How do I uninstall it?

Delete the ClipDock shortcut and the folder %LOCALAPPDATA%\ClipDock. Your history file lives in %APPDATA%\ClipDock; delete that too if you want everything gone.
